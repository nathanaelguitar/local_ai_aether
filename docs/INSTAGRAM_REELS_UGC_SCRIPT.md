# CanopyChat Instagram Reels UGC Script

## Concept

**“Your next question doesn’t need a data center.”**

A casual, selfie-style Reel connecting everyday AI use with energy and water consumption, then introducing CanopyChat as a local-first alternative.

Target length: 25–35 seconds.

## Script

| Time | Visual | Spoken line | On-screen text |
|---|---|---|---|
| 0–3s | Creator holds up a phone, looking skeptical. Add a quick cut to a glass or water bottle. | “Wait… why does asking AI to write one text message need an entire data center?” | `Does every question need a data center?` |
| 3–8s | Quick cuts: server-room imagery, an electricity bill, and a water bottle. Keep it playful, not apocalyptic. | “These systems run in massive facilities that use electricity—and many data centers use water for cooling.” | `Electricity. Cooling. Water.` |
| 8–12s | Creator looks into camera. | “I wanted something that felt a little more intentional for everyday questions.” | `A more local-first option` |
| 12–20s | Screen recording of CanopyChat answering an everyday question. | “This is CanopyChat. Routine chats use an on-device language model, so conversations can stay on your phone by default.” | `On-device intelligence` / `Local-first by default` |
| 20–25s | Show the Web Search toggle briefly, then turn it off. | “When I don’t need current information, I don’t need to use web search.” | `Web search when you choose` |
| 25–31s | Creator holds up the phone and smiles. | “Less unnecessary infrastructure. More control over my data. That’s the kind of AI I actually want to use.” | `CanopyChat` / `Eco-friendly intelligence` |
| 31–35s | App logo and call to action. | “Try CanopyChat and make your next chat a little more local.” | `Try CanopyChat` |

## Conversational version

> “Okay, real question: does asking an AI to rewrite one email really need a giant data center somewhere using electricity and water? I wanted a more local-first option, so I’ve been using CanopyChat. Routine chats run on my phone with on-device intelligence, and web search is there when I choose it. More control, less unnecessary infrastructure. Try CanopyChat.”

## Creator direction

- Film handheld and conversational, as if recommending the app to a friend.
- Use a real everyday prompt: rewriting a text, planning dinner, explaining a receipt, or brainstorming a caption.
- Show the Web Search setting accurately. Do not imply that web search is on-device.
- Avoid exact claims about water use, emissions, or percentage savings unless CanopyChat has a measured, documented comparison.
- Avoid saying CanopyChat has zero environmental impact or that all data stays on-device in every mode.

## Caption

> Not every question needs a trip to the cloud. CanopyChat brings everyday chats on-device, with web search available when you choose it. More control for your conversations—and a more thoughtful approach to the infrastructure behind AI.
>
> Download CanopyChat and try local-first intelligence. 🌳
